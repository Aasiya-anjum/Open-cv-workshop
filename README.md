# Open-cv-workshop
# Week 3 OpenCV Workshop

This beginner project explores image processing and computer vision using Python in Google Colab.

## Workshop Activities

The notebook includes:

- Uploading and displaying an image
- Converting an image to grayscale
- Resizing and cropping an image
- Drawing shapes and text on an image
- Applying Gaussian blur
- Detecting edges with Canny
- Tracking blue objects with a live camera
- Detecting objects with YOLO

## Tools Used

- Python
- Google Colab
- OpenCV
- NumPy
- Matplotlib
- Ultralytics YOLO

## How to Run

1. Open `Open cv[3rd].ipynb` in Google Colab.
2. Run the notebook cells from top to bottom.
3. Upload a JPG or PNG image when Colab asks you to choose one.
4. For live camera activities, allow camera access when your browser asks.
